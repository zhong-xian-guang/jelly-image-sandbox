# 大把抓取：半徑內每顆 Particle 各拉向自己的偏移目標，β 依距離衰減

大把抓取按下時，取指標為圓心、半徑內、被點中那塊 Jelly 上的所有 Particle，各自記下**按下當下相對指標的偏移**與一個依距離衰減的硬度 β（中心 = `grabBeta`、邊緣趨近 0）。拖曳中每顆的目標是「指標 + 自己的偏移」，各自一條位置約束——被抓的一團整團平移、維持形狀。**不**把 ADR-0003 的重心權重從 3 顆推廣到 N 顆。

成員與偏移在按下當下凍結；輸入事件只多帶一個 `handfulRadius`（`grab` 事件的選擇性欄位，沒帶＝原本的單點 Grab；不沿用既有的 `radius`，那是點落在三角形外時的吸附退路半徑，語意不同），展開成 N 條約束的工作在求解器裡做，重播時由 `(x, y, handfulRadius)` 決定性地重現同一把。

## 為什麼

單點 Grab 拉很遠時被拉的部分會變得很細長。成因是：被抓處到本體之間只有一小撮 Particle 承受全部的拉伸。只把入力點攤平到更多 Particle 並不夠——那一團本身的形狀若不受約束，仍然會被抽成細絲。要把那一團本身固定住，細長的「脖子」才會從這團的邊緣開始，粗細等於抓取直徑。

## Considered Options

- **(a) 一條約束、N 顆 Particle 加權**（ADR-0003 公式的直接推廣，拉的是加權平均點）：入力攤平了，但團內相對位置不受約束，照樣會抽絲。沒解決問題。
- **(b) 每顆各一條約束、β 全為 1**：能解決細長，但圈內完全跟手、圈外完全自由，快速甩動時會看到一圈硬邊。
- **(c) 同 (b)、β 依距離衰減**（採用）：只多一個衰減函式，換掉那圈硬邊。半徑調到最小時退化成接近單點 Grab，兩種抓取的手感是連續的。

## Consequences

- 衰減曲線先固定（比照 Tap 的 `(1 − d/R)²`），不開成拉霸；有了第一版試手感後再議。
- 兩把大把抓取重疊時，重疊處的 Particle 同時被兩邊拉，不做特殊處理——與 ADR-0003「Multi-grab 天然共存」同一態度。
- 大把抓取下的快速按放是範圍 Tap：`tap` 事件同樣帶選擇性 `radius`，取代內部固定的 bbox 比例半徑。
- ADR-0003 對一般 Grab 仍然成立，兩者並存。
