# V2 素材工具最小化：疊加單指標 Track 模擬 Multi-grab，不內建影片匯出

V2 素材工具的第一版只做「錄一條輸入事件流（含相機操作）、設起始時間、疊加多條精準重播」，不做 ADR-0005 原本設想的多軌時間軸編輯 UI，也不在 App 內建影片匯出（MediaRecorder 等）——影片素材靠使用者自己用外部螢幕錄影軟體（如 OBS）錄下重播畫面。

## 為什麼

實際觸發需求是：使用者只有單一滑鼠，卻想做出「多點同時抓取＋運鏡」的效果來剪輯影片。這不需要一個給別人用的多軌編輯器，只需要「錄下一次單指標操作＋相機、之後能設起始時間疊加精準重播」——足以把多次單指標錄製疊成一個 Multi-grab 演出（見 `CONTEXT.md` Track／Overlay／Multi-grab 詞條）。影片本身是外部剪輯素材、不會放上 itch.io 頁面，所以不需要在瀏覽器內編碼影片，也不用在意跨平台位元一致（呼應 ADR-0005「v1 不用管跨機器 bit 完全一致」的立場延伸到 v2）。

## Considered Options

- **完整多軌時間軸編輯 UI（原 ADR-0005 設想的樣子）**：更好用，但沒人會拿它給別人編輯素材，先做出來是過度打造。
- **App 內建錄影匯出（MediaRecorder）**：省去外部軟體，但替這個刻意瘦身的 itch.io 靜態包增加編碼相依與複雜度，換來的方便使用者自己已經有 OBS。

## Consequences

- V2 第一版只需要：`applyInput` 事件的錄製／序列化、一個「多條 Track + 各自起始時間 → 疊加播放」的排程器（可能直接沿用/擴充 `DemoRunner` 的 sim-step 排程機制）、極簡的「加一條 Track、設起始時間、播放全部」介面，不需要拖曳時間軸或波形視覺化。
- 之後若真的需要給別人用的編輯體驗，或需要內建匯出，屬於獨立的新決策，不在這次範圍內。
