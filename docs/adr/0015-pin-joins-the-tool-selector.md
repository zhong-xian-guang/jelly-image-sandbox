# 放 Pin 改成工具選擇器裡的一個工具，取代「Pin 模式」勾選框

「Pin 模式」勾選框移除，改成工具選擇器裡的 `pin` 工具。規則原封不動沿用（點空處＝放 Pin、點既有 Pin 附近＝點掉它、快速按放不觸發 Tap），只是觸發來源從勾選框換成選擇器。修訂 ADR-0011 中「Pin 不進選擇器」那一部分；Grab／Tap 仍維持在「一般操作」的手勢辨識裡。

## 為什麼

ADR-0011 當初讓 Pin 留在選擇器外，理由是「沒有使用者需求驅動這個改動」。這個前提已經不成立：

1. 實作上 Pin 模式早就只是「一般操作」底下的子模式（`pinModeActive = pinModeEnabled && activeTool === 'general'`），同時存在兩套切換機制（選擇器 + 勾選框），還需要額外處理「先開 Pin 模式再切到別的工具」這種組合。
2. 加入大把抓取（ADR-0014）後，使用者在試用中明確提出：放 Pin 只在一般操作下能用，不如也做成可以切換的工具。

## Considered Options

- **勾選框與工具並存**：兩個真相來源，拒絕。
- **維持現狀**：勾選框與選擇器的組合語意會隨工具數量繼續變多。

## Consequences

- 錄製與重播不受影響：錄進 Action Track 的已經是 `pin`／`unpin` 事件本身（轉換發生在錄製之前），工具選擇不是事件，片段檔也沒有存 Pin 模式狀態。
- ADR-0011 的「Grab／Pin／Tap 維持手勢辨識」縮小成「Grab／Tap」。
