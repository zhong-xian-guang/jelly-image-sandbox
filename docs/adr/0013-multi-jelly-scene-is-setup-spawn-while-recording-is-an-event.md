# 多塊 Jelly：Scene 是佈景、錄製中的生成／移除才是事件

場上可以同時有多塊 Jelly（`CONTEXT.md` 的 Jelly 定義從「只有一塊」改為「可多塊」）。它們的存在方式由 **Scene（場景）** 這個概念決定：

- **Scene** = 片段第 0 步就存在的那組 Jelly（各自的來源圖、匯入尺寸、網格密度、擺放位置）。**不在錄製中**做的匯入／生成／移除／重建直接改 Scene；`停止／重設` 回到 Scene。
- **錄製中**做的生成／移除錄進 Action Track 當事件：播到那一步才出現／消失，重設後不存在。生成事件攜帶那張圖的參照，片段檔跟著存。
- 只有「清空全部」會把 Scene 連同 Track、群組、片段初始 Pin 一起清成一個新片段；匯入／生成／移除本身**不再**清任何東西（v2 是「重新匯入 = 換掉整塊 = 清空片段」）。

Jelly 之間會碰撞（推開、不穿透、與 ADR-0012 同一套切線摩擦、不黏著）；**不做自碰撞**——一塊對折仍會穿過自己，這是 v1 起的現況。

## 為什麼

2026-09-16 grilling 使用者提出「多個物體互撞」「在鼠標點擊處生成物體」。多塊之後，「Track 播放前 `reset()` 回到 rest」需要一個定義：rest 是哪些塊、放在哪。Scene 就是這個定義。

**Scene 不需要明確拍快照，跟片段初始 Pin 不對稱**：Pin 天生是「操作」，「一開始就在的 Pin」是特例，所以要使用者明確拍下（ADR-0007 追記）；Jelly 反過來——它天生就是佈景，沒有別的存在方式，「錄製中生成」才是特例。強迫使用者為 Jelly 拍快照只會多一步、沒有換到任何資訊。

**匯入從「換掉」變「新增」**：多塊之後「換掉場上唯一那塊」不再有意義；「新增一塊放畫面中央、跟既有的重疊就靠碰撞推開」最直覺，配一顆「清空全部」。

**只做 Jelly 互撞、不做自碰撞**：自碰撞是另一個難度等級（連續碰撞偵測、鄰近三角形排除、翻面時的歧義），需求裡也沒提；使用者已接受對折自穿透的現況。

## Considered Options

- **同一張圖裡不連通的 alpha 區域自動變多塊 Jelly**：不做，維持 v1「只留最大連通元件」；多塊只來自多次匯入／生成。要不要改是獨立決策，不混進來。
- **Softness 等手感設定每塊各自調**：需要「選取哪一塊」的管理 UI，ADR-0010 已為 Fan 刻意避開這套介面，同一理由——全域。
- **生成工具帶素材清單（列出匯入過的圖、選一張再點）**：v3 先只用「最近一次匯入的圖」（沒匯入過就是內建預設果凍），同 ADR-0010 單一實例的精神；清單留給之後有需求再開。
- **生成與移除共用一個工具（點空白處生成、點既有 Jelly 移除）**：想貼著一塊生成卻誤點到它把它刪了——兩個獨立工具最不會誤操作。
- **「把目前狀態拍成 Scene」按鈕**（有重力時讓播放從落地穩定態開始）：不做。使用者放 Jelly 時本來就能直接放地板上、落差很小；而且它意味著 Scene 要存變形後的 Particle 位置而非擺放位置，片段檔形狀複雜一截。
- **場上總 Particle 硬上限**：不設，只靠既有 PerfMonitor 軟退路（使用者 2026-09-16 grilling Q16 明確選擇）。
- **生成工具在 Walled／Floor 範圍外點擊時 clamp 進來或撐大範圍**：拒絕生成（游標提示不可放）。clamp 會把 Jelly 壓扁擠進來；撐大讓「有限桌面」偷偷變動。

## Consequences

- 片段檔升到 **version 2**：`image` + `meshParams` 從單一變成 Scene 裡每塊各一份（含尺寸、密度、擺放位置）；生成事件帶圖參照。載入 v1 檔視為「一塊 Jelly 的 Scene」，舊檔照常能開。
- 生成／移除／重建工具與 Grab 手勢衝突，依 ADR-0011 進工具選擇器。重建只改 Scene、不是事件，錄製中不可用。
- Jelly 需要穩定的 id（依生成順序），碰撞與事件的迭代順序依 id 決定性排序，維持 ADR-0005 的可重播性。
- 既有工具對所有 Jelly 一視同仁：Grab／Pin／Tap 命中哪塊作用哪塊；Fan 矩形內全吹；撒 Pin 落在任一塊表面都算；編隊抓取可跨塊（一手抓兩塊拉開，不禁止）。相機跟隨改用聯集 bbox；Walled 範圍在切換當下依聯集 bbox 展開。
- Track 裡的座標事件指向的那塊被移除後，播放時命中不到東西就 no-op——ADR-0003 既有規則，不特別處理。
- Region 邊長、Tap 半徑、Grab 半徑等「Jelly 對角線 × 係數」的參數改成**每塊各自**的對角線。
- 對折自穿透仍是已知限制；之後若要做自碰撞是獨立決策。
