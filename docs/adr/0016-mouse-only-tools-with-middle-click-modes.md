# 工具收成四個，全用滑鼠操作：左鍵主要、右鍵移除／選單、中鍵單擊切模式

工具選擇器的十個工具收成四個——抓取、Pin、電風扇、Jelly——由側欄頂端的工具列切換。同一工具內的變體改成「模式」（抓取：單點／大把／編隊；Pin：放／拔；電風扇：滾輪要調的參數），在畫布上**中鍵單擊**輪替；中鍵拖曳仍是平移相機。左鍵做主要動作，右鍵單擊做移除或開選單（電風扇右鍵移除、Jelly 右鍵選單「重建／移除」），按住右鍵＋滾輪調目前模式的數值（沒有數值可調時退回縮放）。**不用鍵盤修飾鍵**：鍵盤只有可有可無的快捷鍵（1–4 切工具、空白鍵暫停播放）。取代 ADR-0011 與 ADR-0015 的工具選擇器設計；ADR-0014 的力學不變，大把抓取從獨立工具變成抓取工具的模式。

## 為什麼

2026-09-24 評估介面時，十個工具塞在收合區塊裡的下拉清單，切一次要點三下，而且看不出目前是哪個工具。使用者要求「單用滑鼠做到大部分的操作」、修飾鍵只存在滑鼠上、不考慮觸控；按鍵不夠用就改成切換模式。滑鼠上沒被佔用的只剩右鍵單擊與中鍵單擊，於是：

- **中鍵單擊切模式**：中鍵拖曳本來就是平移相機，點放與拖曳用跟 Tap 同一套門檻區分，互不干擾。模式是看不見的狀態，所以游標旁有標籤、工具卡上也有對應的切換鈕。
- **Pin 的移除走左鍵「拔」模式，不走右鍵**：Pin 工具的右鍵要留給「按住右鍵＋滾輪調筆刷半徑」。若右鍵按下就拔 Pin，想調半徑時會先拔掉游標下的 Pin。使用者認為拔 Pin 比較像換成橡皮擦，接受用模式切換。電風扇的右鍵移除則用「按住期間滾過滾輪就不算移除」來避開同樣的衝突，因為風扇只有一個，移除很少做。
- **Jelly 的移除與重建放進右鍵選單**：左鍵點在既有 Jelly 上仍然是生成，所以原本分成兩個工具想避免的「貼著生成卻誤刪」依然不會發生。

## Considered Options

- **鍵盤修飾鍵（Shift／Alt＋拖曳）**：最常見的做法，但使用者要求只用滑鼠；Firefox 的 Alt 還會叫出選單列。
- **Pin 工具右鍵拔、右鍵拖曳擦**：跟電風扇、Jelly 的「右鍵＝移除」一致，但要靠「右鍵按下先不動作、滾過滾輪就吞掉」這條隱藏規則才能跟調半徑共存。改用模式。
- **工具列浮在畫布邊緣**：跟側欄分開、更像繪圖軟體。先放在側欄頂端，改動較小；面板整體重整時再議。

## Consequences

- 錄進 Track 的事件種類不變（`grab`／`tap`／`pin`／`unpin`／`setFan`……），工具與模式都不是事件，舊片段檔照常重播。
- 撒 Pin 從「點一下撒一片」變成「放」模式下的左鍵拖曳沿路撒；左鍵單擊只放一顆。撒 Pin 與移除 Pin 的半徑合成一條「Pin 筆刷半徑」。
- 之後新增的工具或變體，先考慮能不能變成既有工具的模式，而不是再加一個工具。
